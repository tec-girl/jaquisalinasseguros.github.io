# Jaqui Salinas Seguros — Asesoría en seguros

Página de asesoría en seguros de **Jaqui Salinas**: protege lo que más quieres con un plan a tu medida.

## Seguros

- **Auto**
- **Retiro**
- **Gastos médicos**
- **Vida**
- **Educación**

## Secciones del sitio

- **Proceso** — cómo contratar, paso a paso.
- **Sobre mí** — trayectoria de Jaqui Salinas.
- **Galería** y **Videos**.
- **Preguntas** frecuentes.
- **Contacto**.

## El sitio

- Estático, en HTML, CSS y JavaScript puro, sin compilación.
- Disponible en **seis idiomas**: español, English, français, Deutsch, 中文 y português.
- Diseño en verde azulado profundo y dorado.

| Archivo | Función |
| --- | --- |
| `index.html` | Página principal |
| `script.js` | Interactividad y formularios |
| `style.css` | Estilos |
| `assets/` | Imágenes y recursos |

## Cómo ejecutarlo

Abrir `index.html` en un navegador moderno, o servir la carpeta:

```bash
python3 -m http.server 8000
```
